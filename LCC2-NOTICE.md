# LCC2 format notice

The LCC2 data organization format originated from XGRIDS.

This repository contains an independent implementation that creates LCC2 v0.0.3
packages from PLY inputs. It is not an official XGRIDS implementation. The
implementation maps supplied and generated levels into spatial nodes beneath
the LCC2 root and therefore modifies the data organization described in the
source whitepaper.

Specification and license:
https://github.com/xgrids/LCC2Whitepaper

Use and redistribution of LCC2 data produced by this project are subject to the
terms in that whitepaper.
